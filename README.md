AI Reports com Excel, GPT Agents e Claude Code

# Projeto de Curso — DIO

Projeto desenvolvido como trabalho de conclusão do curso de Análise de Dados com Inteligência Artificial.

---

## O que foi feito

Agentes de IA para automatizar o tratamento e a análise de uma base de dados real de vendas de veículos Porsche. O dataset chegou com dados sujos — datas inconsistentes, valores monetários em formatos variados, erros de digitação e muito mais.

Com o **ChatGPT Agents** e o **Claude**, os agentes que leram a planilha, identificaram e corrigiram todos esses problemas automaticamente, e geraram uma base limpa pronta para análise. Em seguida, a IA para criou dashboards e melhorou a formatação do Excel — tudo via linguagem natural, sem escrever código manualmente.

---

## Modificação própria

Como contribuição ao projeto, fOI FEITO uma adaptação focada nas compradoras: o agente foi ajustado para identificar automaticamente quais clientes são mulheres e gerar uma visão segmentada das compras femininas, permitindo análises como ticket médio e modelos preferidos por esse público.
